# Client installeren

Voor de eerste release delen we de Prism-instanties als ZIP-bestanden via het officiële Discord-kanaal. Wacht op de release-aankondiging: de huidige testbestanden zijn nog geen spelersrelease.

1. Download en installeer Prism Launcher via de [officiële downloadpagina](https://prismlauncher.org/download/). Open Prism en volg de eerste installatiestappen.
2. Meld in Prism je Microsoft-account aan via **Accounts → Manage Accounts → Add Microsoft**. Gebruik het account waarop je Minecraft: Java Edition bezit en volg de aanmeldstappen. Deel je wachtwoord of aanmeldcode met niemand.
3. Download **Essentials** of **Extended** uit de release-aankondiging. Essentials is de eenvoudige standaardkeuze; Extended voegt extra gereedschap en visuele opties toe.
4. Kies in Prism **Add Instance → Import** en selecteer het gedownloade ZIP-bestand. Importeer de twee varianten als afzonderlijke instanties als je beide wilt gebruiken.
5. Start de instantie en laat de eerste synchronisatie afronden voordat Minecraft opent. Meld een fout als de synchronisatie of installatie stopt.
6. Gebruik de servergegevens uit de release-aankondiging om verbinding te maken.

De instantie controleert bij het starten op goedgekeurde clientupdates. Werk mods in deze instantie niet zelf in één keer bij via Prism. Bewaar je persoonlijke instellingen en werelden; een nieuwe Minecraft-versie krijgt een nieuwe instantie.

Noteer bij een probleem welke variant en release je gebruikt en volg [de meldinstructies](/Hearthstone-SMP-Public/problemen-melden/).
