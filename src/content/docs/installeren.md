# Client installeren

Voor de eerste release delen we de Prism-instanties als ZIP-bestanden via het officiële Discord-kanaal. Wacht op de release-aankondiging: de huidige testbestanden zijn nog geen spelersrelease.

1. Installeer Prism Launcher als je dat nog niet hebt.
2. Download **Essentials** of **Extended** uit de release-aankondiging. Essentials is de eenvoudige standaardkeuze; Extended voegt extra gereedschap en visuele opties toe.
3. Kies in Prism **Add Instance → Import** en selecteer het gedownloade ZIP-bestand. Importeer de twee varianten als afzonderlijke instanties als je beide wilt gebruiken.
4. Start de instantie en laat de eerste synchronisatie afronden voordat Minecraft opent. Meld een fout als de synchronisatie of installatie stopt.
5. Gebruik de servergegevens uit de release-aankondiging om verbinding te maken.

De instantie controleert bij het starten op goedgekeurde clientupdates. Werk mods in deze instantie niet zelf in één keer bij via Prism. Bewaar je persoonlijke instellingen en werelden; een nieuwe Minecraft-versie krijgt een nieuwe instantie.

Noteer bij een probleem welke variant en release je gebruikt en volg [de meldinstructies](/Hearthstone-SMP-Public/problemen-melden/).
