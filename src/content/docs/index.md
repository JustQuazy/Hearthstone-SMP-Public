# Hearthstone SMP

Hearthstone SMP is een langdurige survivalwereld met een herkenbare Minecraft-basis en gerichte verbeteringen. Deze handleiding helpt je de juiste client te installeren en problemen te melden.

De client en de server worden nog getest. Gebruik alleen een download die in het officiële Discord-kanaal als huidige release is aangekondigd. De starttijd en servergegevens volgen in de release-aankondiging.
